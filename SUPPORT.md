# Support — mailctl

- **Bugs and feature requests:** open an [issue](https://github.com/aeon022/mailctl/issues). Please include your version (`mailctl --version`), OS, and the exact steps.
- **Docs:** https://missionctl.sh/docs
- **Email:** hello@abteilung83.com — I answer within 3 to 5 working days. This is a one-person project; there is no 24/7 support.
